# K-labo 公式サイト

福岡県筑紫野市紫・紫駅東口すぐのカフェ＆テイクアウトショップ「K-labo」の公式サイト。

コンセプト：アジアを原点にしながら、ジャンルにとらわれず日々のおいしいものをつくる店。

- Next.js（App Router）+ TypeScript + Tailwind CSS v4
- 全ページ静的生成。Vercelにそのままデプロイ可能。

## コマンド

```bash
npm run dev        # 開発サーバー
npm run build      # 本番ビルド
npm run lint       # ESLint
npm run typecheck  # 型チェック
```

## メニュー価格の更新

価格は次のどちらかの方法で更新できます。

### A. Googleスプレッドシートで管理する（お店の方向け・おすすめ）

1. [docs/menu-prices-template.csv](docs/menu-prices-template.csv) をGoogleスプレッドシートに読み込む
   （ファイル → インポート → アップロード）
2. 「価格」列に税込価格を数字で入力（例: `650`）。空欄の商品は価格を表示しません
3. ファイル → 共有 → **ウェブに公開** → 対象シートを選び、形式を「カンマ区切り形式（.csv）」にして公開
4. 表示されたURLを、Vercel の環境変数 `MENU_SHEET_CSV_URL` に設定して再デプロイ（初回のみ）

以降はスプレッドシートを編集するだけで、**約10分以内**にサイトへ反映されます。

| 列 | 入力内容 |
| --- | --- |
| id | 商品の識別子（変更しないでください） |
| 商品名 | 管理用の目印（サイトには反映されません） |
| 価格 | 税込価格（数字）。空欄なら未掲載 |
| 価格の補足 | 例: `〜`、`（2個入り）` |
| 区分 | `定番`（価格を掲載）または `変動`（「Instagramでご確認ください」と表示） |
| 提供状況 | `休止` または `売り切れ` と書くと「ただいま休止中」を表示 |

- 商品の追加・写真の変更・商品名の変更は [src/data/menu.ts](src/data/menu.ts) で行います
- スプレッドシートが読み込めない場合は、自動的に menu.ts の値で表示されます

### B. ファイルを直接編集する

[src/data/menu.ts](src/data/menu.ts) の `price: null` を `price: 650` のように書き換えて保存
（GitHub上で編集してコミットすれば、Vercelが自動で再公開します）。

## 本番URL

本番ドメインは **[www.skic.jp](https://www.skic.jp)** です。
[src/data/siteConfig.ts](src/data/siteConfig.ts) の `url` で管理しており、
canonical / OGP / sitemap.xml / robots.txt / 構造化データがこの値を使います。

ドメインを変更する場合は、この値（または環境変数 `NEXT_PUBLIC_SITE_URL`）を
必ず更新してください。**実際の公開ドメインと違う値のままにすると、検索エンジンに
別URLを正規版として伝えてしまい、本来のドメインが検索結果に出なくなります。**

## 画像について

`/public/images/` にカテゴリ別で配置しています。

> 素材共有でいただいた `public/images/LINE_ALBUM_*.jpg`（元データ）は、使用する写真を各フォルダへ
> 名前を付けて複製済みです。`public/` 内のファイルはすべて公開・配信対象になるため、
> 公開前に元データは `public/` の外へ移動してください。

| フォルダ | 内容 |
| --- | --- |
| `brand/` | ロゴ（原本 + 背景透過処理した3色版・モノグラム） |
| `hero/` | トップページのヒーロー写真 |
| `food/` | バインミー・丼・オリエンタルメニューなど |
| `delica/` | お弁当・お惣菜・オードブル |
| `sweets/` | 彩りバターサンド・ストロープワッフルなど |
| `drinks/` | レモネード・アイスコーヒー |
| `shop/` | 外観・店内 |
| `story/` | 仕込み・調理風景、バンコクの風景 |

### ロゴの3色版について

公式ロゴ（`brand/k-labo-logo-original.jpg`）はダークブラウン背景のJPEGのため、
輝度からアルファマスクを生成して背景を透過したPNGを用意しています。

- `k-labo-logo-ink.png` — 明るい背景用（ヘッダー等）
- `k-labo-logo-ivory.png` — 暗い背景用（ヒーロー・フッター）
- `k-labo-logo-gold.png` — 原色
- `k-labo-mark-*.png` — 円形モノグラムのみ

ロゴ原本を差し替える場合は、同じ手順で3色版を再生成してください。

### 写真の差し替え

各データファイルの `image` / `src` にパスを書き換えるだけで反映されます。
ヒーロー写真は [Hero.tsx](src/components/sections/home/Hero.tsx) の `HERO_IMAGES` で
PC用（集合写真）とスマートフォン用（単品写真）を別々に指定しています。
差し替える際は `src` と元画像の `width` / `height` を書き換えてください。
